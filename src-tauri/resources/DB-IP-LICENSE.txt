The bundled file country-ipv4.bin.gz is a derived, compressed representation of
DB-IP country lite data (IPv4 ranges only). It is used solely to show a country
flag for a server address and is never sent anywhere.

Regenerate with:
  node scripts/build-country-db.mjs <dbip-country-lite.csv[.gz]> src-tauri/resources/country-ipv4.bin.gz
