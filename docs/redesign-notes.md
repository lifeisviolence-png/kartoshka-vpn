# Переработка Windows-интерфейса

Режим: сохранение узнаваемой структуры с визуальной переработкой. За основу взят утверждённый пользователем скриншот KartoshkaVPN; новая просьба уточняет стиль: более плоский тёмно-фиолетовый liquid-glass, ясная кнопка и увеличенная типографика.

Сохраняются фирменный знак, основная навигация, импорт, выбранный сервер, реальные состояния, данные подписки и возможность диагностики. Убираются визуальный шум, слишком мелкие подписи и создающие ложное впечатление элементы управления. Основной текст — читаемый размер, с хорошим контрастом; панели — полупрозрачные, с тонкими границами и сдержанным размытием; движение — короткое, с учётом настройки уменьшения анимации в Windows.

Основной технический риск — переключение ядра и восстановление системного proxy. Старые версии в Git сохранены; удалять пользовательские конфигурации и скрыто менять режим подключения нельзя. Приложения, которые не используют системный proxy, могут работать напрямую.
