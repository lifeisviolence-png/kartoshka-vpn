# KartoshkaVPN для Windows

KartoshkaVPN — клиент подписок 3x-ui с интерфейсом Tauri и ядром Xray-core. Пользователь импортирует ссылку подписки или отдельный сервер, выбирает его и включает подключение. Версия 0.9.6 доступна для обычного использования; статус сборки и проверок указан в GitHub Actions и заметках конкретного выпуска.

## Что нового в 0.9
- Серверы сгруппированы по странам: флаг, название на языке интерфейса, число серверов и лучший пинг в заголовке; группы сворачиваются, список сортируется по стране, пингу и имени.
- Страна определяется по флагу или названию в подписке, а если их нет — по IP сервера через офлайн-базу DB-IP Lite. Флаги — SVG из flag-icons. Обе библиотеки распространяются по открытым лицензиям, файлы лицензий входят в установщик.
- Можно держать несколько подписок: у каждой своё имя, дата обновления, срок и трафик. Удаление подписки убирает только её серверы и отменяется в течение 8 секунд.
- Обновление подписки не затрагивает остальные: узлы сопоставляются по протоколу, хосту, порту и ключу, а при смене UUID — по адресу и транспорту, поэтому избранное, пользовательское имя и выбранный сервер сохраняются.
- «Проверить пинг всех» опрашивает серверы с ограничением параллельности, показывает прогресс и отменяется. Для Hysteria2 TCP-пинг неприменим, поэтому задержка измеряется отдельным одноразовым ядром.
- Отладочный журнал ядра включается в настройках и в логах: файл `core.log` рядом с `app.log` в `%APPDATA%\ru.kartoshka.vpn`. Он помогает разобрать TLS и UDP-проблемы Hysteria2, но может содержать адреса серверов.
- Интерфейс переработан: нейтральная тёмная тема, акцент `#7C5CFF`, Inter/Segoe UI, компактный сайдбар, плотные строки, видимый фокус и поддержка reduced motion.
## Важные ограничения

Приложение использует системный прокси Windows и не включает TUN, виртуальный адаптер или изменение маршрутов ОС. **Приложения, которые игнорируют системный прокси, могут работать напрямую.** До использования на важном устройстве нужно проверить подключение и корректное восстановление прежних настроек после отключения. Одновременная работа с другими прокси-приложениями может приводить к конфликту; при выявленном конфликте приложение сообщает об ошибке и не должно молча перезаписывать чужие параметры.

Подключение блокируется только тогда, когда в Windows уже включён чужой прокси-сервер: перезаписывать настройки другого VPN нельзя. Автоопределение параметров (по умолчанию включено в Windows) и PAC-файл не блокируют запуск: приложение сохраняет их, временно отключает на время сеанса и возвращает после отключения. При принудительном завершении приложения отдельный процесс пытается восстановить исходные параметры, однако гарантировать восстановление при одновременном завершении всех процессов, сбое Windows или конфликтующей записи сторонней программы невозможно. В таких случаях может потребоваться ручная проверка настроек Windows.

Поддерживаются распространённые ссылки VLESS/Reality, VMess, Trojan, Shadowsocks и Hysteria2 в пределах реализованных параметров. Некорректные и неподдерживаемые варианты не объявляются рабочими; подробности — в `docs/xray-protocols.md`. Некоторые серверы, импортированные старыми версиями с XHTTP, необходимо повторно импортировать, так как старая версия не сохранила часть параметров.

Если в ссылке указан `allowInsecure` (Xray 26 удалил этот параметр), узел не отбрасывается: при первом подключении клиент запоминает отпечаток сертификата сервера и дальше проверяет именно его. Это защищает от подмены сертификата, но не заменяет проверку доверия к самому серверу.

Подписка может передавать собственный профиль маршрутизации (JSON-профиль Xray или ссылку `happ://routing/onadd/...`). В режиме «Умная маршрутизация» используются эти правила; если провайдер их не передаёт, применяются встроенные: локальные и российские адреса — напрямую, остальное — через сервер. Источник правил виден в настройках. Язык интерфейса переключается между русским и английским.

Режим «Россия напрямую» использует geosite/geoip из официального пакета Xray и может выполнять локальное DNS-разрешение. Полнота и актуальность списков не гарантируются. Выбор режима меняется после отключения. Дата и трафик подписки отображаются только если поставщик передаёт соответствующие данные.

Локальные настройки приложения и ссылки подписки могут содержать ключи доступа: не публикуйте их и не отправляйте полный файл конфигурации третьим лицам. Браузерный Preview демонстрирует интерфейс и не может включать системный прокси.

В старых версиях мог остаться файл `sing-box.json` с конфигурацией в каталоге настроек приложения `%APPDATA%\ru.kartoshka.vpn`. Новая версия не удаляет старые файлы автоматически, чтобы не повредить данные; обращайтесь с ними как с секретными. Для нового ядра конфигурация передаётся в процесс через стандартный ввод.

## Сборка и тесты

Подробности сборки и диагностические ограничения — в `DESKTOP.md`, инструкция по диагностике Windows — в `diagnostics/README.md`. Windows workflow находится в `.github/workflows/desktop.yml`, использует закреплённый Xray v26.10.31 и проверяет SHA-256 официального ZIP. Не устанавливайте тестовую сборку, не ознакомившись с её статусом и ограничениями.

```sh
pnpm install --frozen-lockfile
pnpm run build
node --test tests/xray-config.test.js
```

Чтобы дополнительно проверить генератор реальным Xray и изолированными локальными серверами, установите `XRAY_TEST_BIN` и `XRAY_LOCATION_ASSET`; точные команды указаны в `docs/xray-protocols.md`. Эти тесты не заменяют проверку Windows и реального VPN-сервера.
