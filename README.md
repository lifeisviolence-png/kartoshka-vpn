# KartoshkaVPN

KartoshkaVPN — лёгкий Windows-клиент для личных proxy-подписок. Пользователь выбирает сервер и нажимает одну большую кнопку подключения. Приложение запускает сетевое соединение, включает системный proxy Windows и проверяет реальный выход в интернет через выбранный сервер.

## Поддерживаемые конфигурации

Поддерживается импорт subscription URL 3x-ui, прямых ссылок и нескольких ссылок построчно. Парсер и sing-box-конфигурация рассчитаны на VLESS/VLESS Reality, VMess, Trojan, Shadowsocks, SOCKS и Hysteria2 в пределах параметров, которые переданы в ссылке.

## Важные ограничения

KartoshkaVPN использует системный proxy Windows. Это не перенаправляет автоматически приложения, которые игнорируют системные proxy-настройки. TUN, виртуальные адаптеры и изменение маршрутов Windows полностью исключены из текущего пользовательского режима.

Перед включением приложение сохраняет предыдущие настройки системного proxy. При отключении, ошибке, переключении сервера и закрытии приложения сохранённые значения восстанавливаются. Статус «Подключено» показывается только после проверки локального proxy и реального запроса определения внешнего IP через него.

## Preview и native-запуск

Preview показывает интерфейс, но не может включить системный proxy. Для реального подключения нужна Windows-сборка с bundled сетевым компонентом:

```bash
pnpm install
pnpm desktop:dev
```

Для восстановления сети после старой версии используйте `diagnostics/restore-windows-network.ps1` через PowerShell от имени администратора.
