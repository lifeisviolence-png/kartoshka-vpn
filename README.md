# KartoshkaVPN для Windows

KartoshkaVPN — клиент подписок 3x-ui с интерфейсом Tauri и ядром Xray-core. Пользователь импортирует ссылку подписки или отдельный сервер, выбирает его и включает подключение. Версия 0.7.0 предназначена для предварительного тестирования; статус сборки и проверок указан в GitHub Actions и заметках конкретного выпуска.

## Важные ограничения

Приложение использует системный прокси Windows и не включает TUN, виртуальный адаптер или изменение маршрутов ОС. **Приложения, которые игнорируют системный прокси, могут работать напрямую.** До использования на важном устройстве нужно проверить подключение и корректное восстановление прежних настроек после отключения. Одновременная работа с другими прокси-приложениями может приводить к конфликту; при выявленном конфликте приложение сообщает об ошибке и не должно молча перезаписывать чужие параметры.

В целях безопасности подключение блокируется, если в Windows уже включён другой прокси, PAC или автоопределение параметров, либо состояние неоднозначно. При принудительном завершении приложения отдельный процесс пытается восстановить исходные параметры, однако гарантировать восстановление при одновременном завершении всех процессов, сбое Windows или конфликтующей записи сторонней программы невозможно. В таких случаях может потребоваться ручная проверка настроек Windows.

Поддерживаются распространённые ссылки VLESS/Reality, VMess, Trojan, Shadowsocks и Hysteria2 в пределах реализованных параметров. Некорректные и неподдерживаемые варианты не объявляются рабочими; подробности — в `docs/xray-protocols.md`. Некоторые серверы, импортированные старыми версиями с XHTTP, необходимо повторно импортировать, так как старая версия не сохранила часть параметров.

Режим «Россия напрямую» использует geosite/geoip из официального пакета Xray и может выполнять локальное DNS-разрешение. Полнота и актуальность списков не гарантируются. Выбор режима меняется после отключения. Дата и трафик подписки отображаются только если поставщик передаёт соответствующие данные.

Локальные настройки приложения и ссылки подписки могут содержать ключи доступа: не публикуйте их и не отправляйте полный файл конфигурации третьим лицам. Браузерный Preview демонстрирует интерфейс и не может включать системный прокси.

В старых версиях мог остаться файл `sing-box.json` с конфигурацией в каталоге настроек приложения `%APPDATA%\ru.kartoshka.vpn`. Новая версия не удаляет старые файлы автоматически, чтобы не повредить данные; обращайтесь с ними как с секретными. Для нового ядра конфигурация передаётся в процесс через стандартный ввод.

## Сборка и тесты

Подробности сборки и диагностические ограничения — в `DESKTOP.md`, инструкция по диагностике Windows — в `diagnostics/README.md`. Windows workflow находится в `.github/workflows/desktop.yml`, использует закреплённый Xray v26.10.31 и проверяет SHA-256 официального ZIP. Не устанавливайте тестовую сборку, не ознакомившись с её статусом и ограничениями.

```sh
pnpm install --frozen-lockfile
pnpm run build
node --test tests/xray-config.test.js
```

Чтобы дополнительно проверить генератор реальным Xray и изолированными локальными серверами, установите `XRAY_TEST_BIN` и `XRAY_LOCATION_ASSET`; точные команды указаны в `docs/xray-protocols.md`. Эти тесты не заменяют проверку Windows и реального VPN-сервера.
