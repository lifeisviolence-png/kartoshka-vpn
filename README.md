# КартошкаVPN

Лёгкий интерактивный v0 интерфейса VPN-клиента для Windows/macOS. Прототип показывает основной пользовательский сценарий: выбор сервера, кнопку подключения, режим маршрутизации, дату окончания подписки и состояния соединения.

## Запуск

```bash
pnpm install
pnpm run dev
```

Приложение открывается на `http://localhost:3000`.

## Важно

Текущая версия — браузерный UI-прототип. Она не меняет системный прокси, не создаёт TUN-интерфейс и не загружает реальные geofiles. Для этого в `src/desktop-bridge.js` оставлен контракт, который следующим этапом можно заменить на нативный адаптер sing-box/Xray внутри Tauri или другой desktop-shell.
