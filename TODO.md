# КартошкаVPN — результаты первой версии

- [x] **Главный экран подключения**
  - Есть большая кнопка подключения и отключения.
  - Компоновка остаётся минималистичной и не перегружена дополнительными функциями.
  - Отображаются четыре состояния: «Не подключено», «Подключение», «Подключено» и «Ошибка» с понятным пользовательским сообщением.

- [x] **Серверы подписки 3x-ui**
  - На экране есть демонстрационный список серверов.
  - Для каждого сервера показываются название, страна/город и задержка.
  - Пользователь может выбрать сервер.

- [x] **Подписка и основной режим**
  - Показывается дата окончания демонстрационной подписки.
  - «Локальный прокси» выделен как рекомендуемый и рабочий сценарий первой версии.
  - В интерфейсе предусмотрены точки расширения для subscription URL и обновления конфигурации.

- [x] **Маршрутизация**
  - Доступен выбор «Россия напрямую, зарубежные сайты через прокси».
  - Доступен выбор «Весь трафик через прокси».
  - Доступен выбор «Ручной режим».

- [x] **Архитектура desktop-ядра**
  - Интерфейс использует адаптерный контракт для будущего sing-box/Xray.
  - Прототип честно сообщает, что браузерная версия не является системным VPN и не поднимает TUN.

- [x] **Windows/macOS оболочка — UI v0**
  - Основные элементы одинаково работают в широком и узком окне.
  - Структура подготовлена для последующей упаковки в Tauri или другой desktop-shell.

- [x] **Нативный desktop-этап — proxy MVP**
  - Подключён sing-box sidecar с локальным mixed HTTP/SOCKS-прокси.
  - Системный прокси Windows/macOS включается самим sing-box через `set_system_proxy`.
  - Добавлен импорт subscription URL из 3x-ui и разбор vless/vmess/trojan/ss.
  - Добавлены GitHub Actions для Windows x64, macOS Intel и macOS Apple Silicon.

- [ ] **Следующий сетевой этап**
  - Подключить полноценные geoip/geosite rule-sets с проверяемыми версиями.
  - Добавить динамическое отображение срока и трафика из `subscription-userinfo`.
  - Отдельно исследовать TUN/Network Extension, не включая его в качестве рабочего режима по умолчанию.
