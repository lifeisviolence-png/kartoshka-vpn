# KartoshkaVPN changelog

## v0.6.1

- Добавлен постоянный snapshot предыдущих Windows proxy-настроек в защищённой пользовательской папке приложения.
- Snapshot записывается атомарно до изменения Registry и восстанавливается при следующем запуске после аварийного завершения.
- Ошибки `reg.exe` больше не игнорируются; подключение откатывается при ошибке записи proxy.
- Локальный порт `127.0.0.1:2080` проверяется вместе с PID запущенного дочернего `sing-box`.
- Добавлен мониторинг завершения процесса и событие ошибки для интерфейса.
- Перед запуском выполняется `sing-box check -c`.
- Добавлена отдельная задержка через активный proxy в дополнение к прямому TCP ping сервера.
- Импорт подписок теперь возвращает ошибки по строкам, а обновление сохраняет ручные узлы, избранное и пользовательские поля.
- Добавлены рабочие экраны настроек, статистики и логов.
- Добавлены Windows smoke-test в GitHub Actions и диагностический PowerShell-скрипт.

## Проверка

Frontend build и JavaScript parser tests выполняются в Sandbox. Native Rust/Tauri build и Windows smoke-test выполняются в Windows CI; локальный Sandbox не является Windows и не может подтвердить работу Registry, системного proxy или внешний IP через реальный сервер пользователя.
