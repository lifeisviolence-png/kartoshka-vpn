# KartoshkaVPN changelog

## v0.8.0
- Исправлена главная причина отказа импорта: ответ подписки разбирался по любым пробелам, поэтому названия вида «🇩🇪 Германия 1» разрывали ссылки на куски и весь импорт отменялся. Теперь ссылки делятся только по переводу строки и по началу схемы; несколько ссылок в одной строке тоже поддерживаются.
- `allowInsecure` больше не приводит к отказу: Xray 26 удалил этот параметр, поэтому клиент закрепляет сертификат сервера при первом подключении (TOFU) и сохраняет отпечаток SHA-256 вместе с узлом. Отпечаток сверен с выводом `openssl x509 -fingerprint -sha256`.
- Неизвестные параметры ссылок стали предупреждениями и больше не блокируют импорт; поддержаны `mode=gun/multi` для gRPC, `ed/eh` для WebSocket, JSON-профили Xray и ссылки маршрутизации `happ://routing/onadd/...`.
- Частично читаемая подписка больше не применяется молча: показывается окно «Результат импорта» с числом прочитанных ссылок, списком ошибок и предупреждений, а запись выполняется только по кнопке «Импортировать доступные». Повреждённые строки не удаляют сохранённые серверы.
- Маршрутизация: режимы «Через сервер», «Умная маршрутизация» и «Россия напрямую». Умный режим берёт правила из подписки (JSON-профиль или happ-ссылка), а при их отсутствии использует встроенные правила: локальные и российские адреса — напрямую, остальное — через сервер. Источник правил показан в настройках.
- Добавлен переключатель языка интерфейса (русский/английский). Переведены все экраны, сообщения об ошибках импорта и конфигурации, названия стран; выбор сохраняется.
- Отпечаток сертификата и старые подписки: узлы, сохранённые предыдущими версиями, продолжают работать, а страны в списке переключаются вместе с языком.
- Автоматически проверено: 17 тестов конфигурации Xray (включая реальное ядро 26.10.31 и закреплённый сертификат), 10 фронтенд-тестов (частичный импорт, ротация UUID, язык, закрепление сертификата), 3 интеграционных теста с реальным Xray (HTTP CONNECT, SOCKS5, Hysteria2 + Salamander, маршрутизация .ru), 10 Windows-тестов, сборка NSIS и тихая установка. Границы проверки — в docs/windows-verification.md.
- Не проверено: реальная подписка пользователя и его серверы, настоящая перезагрузка Windows, сон и гибернация, антивирус и SmartScreen (установщик не подписан).

## v0.7.0 — предварительная версия
- Ядро заменено на Xray-core v26.10.31: официальный релиз, SHA-256 сверяется в CI; sing-box в этой версии не используется.
- Импорт подписок 3x-ui: VLESS (включая Reality и XHTTP), VMess, Trojan, Shadowsocks и Hysteria2 в реализованных вариантах. Неподдерживаемые узлы сохраняются с причиной и не запускаются.
- Обновление подписки сохраняет ручные серверы, избранное, выбранный узел и пользовательские названия; частичный импорт отклоняется, а не применяется молча.
- Системный прокси Windows: снимок прежних значений в DPAPI, запись только при отсутствии чужого proxy/PAC/автоопределения, проверка владельца локальных портов, откат при ошибке записи.
- Отдельный watchdog восстанавливает настройки после аварийного завершения GUI, ядра или самого watchdog. При чужом вмешательстве настройки не перезаписываются, снимок сохраняется.
- `FLAGS_UI` Windows считается производным значением: проверяются биты PAC/автоопределения и сами значения реестра, а не точное слово флагов. Отсутствующий нулевой `AutoDetect`/`ProxyEnable` приравнен к `0`, потому что Windows удаляет и воссоздаёт эти значения сама.
- Интерфейс переработан: главный экран, серверы, статистика, логи, настройки, «О программе»; тёмная фиолетовая тема.
- Автоматически проверено: 16 фронтенд-тестов, 13 тестов конфигурации Xray (включая реальное ядро и HTTP-запрос через локальный прокси), 10 Windows-тестов на одноразовом Windows-раннере (реальные записи HKCU, отказы при чужом proxy, матрица аварийных завершений), сборка NSIS, тихая установка и запуск установленного Xray с геоданными. Подробности и границы проверки — в docs/windows-verification.md.
- Не проверено: реальная подписка и реальный сервер, настоящая перезагрузка Windows, сон и гибернация, антивирус и SmartScreen (установщик не подписан), одновременная гибель GUI, ядра и watchdog.

## v0.6.1

Примечание: приведённые ниже исторические заявления не являются подтверждением безопасности версии v0.6.1. В частности, ранняя реализация восстановления не гарантировала восстановление при аварийном завершении.

- Добавлен постоянный snapshot предыдущих Windows proxy-настроек в защищённой пользовательской папке приложения.
- Snapshot записывается атомарно до изменения Registry и восстанавливается при следующем запуске после аварийного завершения.
- Ошибки `reg.exe` больше не игнорируются; подключение откатывается при ошибке записи proxy.
- Локальный порт `127.0.0.1:2080` проверяется вместе с PID запущенного дочернего `sing-box`.
- Добавлен мониторинг завершения процесса и событие ошибки для интерфейса.
- Перед запуском выполняется `sing-box check -c`.
- Добавлена отдельная задержка через активный proxy в дополнение к прямому TCP ping сервера.
- Импорт подписок теперь возвращает ошибки по строкам, а обновление сохраняет ручные узлы, избранное и пользовательские поля.
- Добавлены рабочие экраны настроек, статистики и логов.
- Добавлены Windows smoke-test в GitHub Actions и диагностический PowerShell-скрипт.

## Проверка

Frontend build и JavaScript parser tests выполняются в Sandbox. Native Rust/Tauri build и Windows smoke-test выполняются в Windows CI; локальный Sandbox не является Windows и не может подтвердить работу Registry, системного proxy или внешний IP через реальный сервер пользователя.
