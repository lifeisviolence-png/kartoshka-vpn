# Сборка KartoshkaVPN для Windows

Проект использует Tauri 2 и Xray-core v26.10.31. Основной способ сборки — `.github/workflows/desktop.yml`: Windows runner устанавливает закреплённые зависимости, скачивает официальный архив Xray и сверяет его SHA-256, добавляет `xray.exe`, `geoip.dat`, `geosite.dat` и лицензии, генерирует иконки и собирает NSIS-установщик. `wintun.dll` не включён. Конфигурация Xray перед запуском проверяется штатной командой `xray run -test`.

Установщик и результат работы workflow доступны в разделе GitHub Actions и, при успешной сборке тега, в Releases. Новые сборки помечаются предварительными; запуск проверок в CI не подтверждает работоспособность на каждом пользовательском компьютере или с любым сервером.

На Windows системный HTTP-прокси используется на `127.0.0.1:2080`, локальный SOCKS — на `127.0.0.1:2081`. Обе службы привязаны только к loopback. Серверы импортируются из предоставленной пользователем подписки; встроенных демонстрационных серверов нет. Работоспособность серверных протоколов зависит от параметров конкретной подписки и удалённого сервера.

До запуска локальной сборки необходимо подготовить официальный Xray, файлы геоданных, лицензии и иконки тем же способом, что в Windows workflow. Простой `pnpm desktop:build` без этих подготовленных файлов не является самодостаточной командой.

Сведения по безопасной read-only диагностике см. `diagnostics/README.md`. Не запускайте настройки Windows через старые скрипты сброса вслепую; они могут повлиять на другие прокси. Код и конфигурации подписок содержат секреты и не должны попадать в журнал, CI или тикеты.
